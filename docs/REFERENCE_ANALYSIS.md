# Reference product review — Turfly

Reference: https://turfly.app/

TurfMate takes inspiration from common product patterns visible in sports-booking products: search-first discovery, venue cards, area and sport filters, date-based slot selection, checkout summaries, booking history and a separate venue-owner path.

TurfMate will maintain its own brand, wording, visual assets, navigation details and interaction design. The goal is to learn from the customer journey, not reproduce another company's source code, exact page layouts, branding or proprietary assets.

## TurfMate's product choices

- Football-first launch focus for Dhaka.
- A clear distinction between illustrative sample data and verified live inventory.
- A saved shortlist that works before account creation.
- A booking flow that displays the full price and proposed advance before checkout.
- An owner workflow that eventually unifies online, phone, WhatsApp and walk-in bookings.
- Community, Academy, Tournaments and Store introduced after reliable booking is established.
